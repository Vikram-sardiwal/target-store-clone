# 🎯 Target Clone (React)

A responsive Target-inspired e-commerce frontend built with React, Vite, and Tailwind CSS. This project replicates the modern shopping experience with a clean UI, responsive design, and reusable React components.

## 🚀 Live Demo

🔗 https://target-ecommerce-clone.vercel.app


## ✨ Features

- 🛍️ Responsive E-commerce UI
- 🔍 Product Search
- 🛒 Add to Cart
- ❤️ Wishlist
- 👤 User Profile
- 📦 Product Categories
- 💳 Checkout Page
- 📱 Mobile Friendly Design
- ⚡ Fast Performance with Vite

---

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- React Router DOM
- JavaScript (ES6+)
