# 🎯 Target Clone (React)

A responsive Target-inspired e-commerce frontend built with React, Vite, and Tailwind CSS. This project replicates the modern shopping experience with a clean UI, responsive design, and reusable React components.

## 🚀 Live Demo

🔗 https://target-ecommerce-clone.vercel.app


## ✨ Features

- 🔐 Login form with validation
- 📝 Profile form validation
- 📍 Checkout address validation
- 📱 Fully responsive UI
- 🧩 Reusable React components
- 🛒 Cart management
- ❤️ Wishlist functionality
- 🔎 Product search
- 🧭 React Router navigation

---

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- React Router DOM
- JavaScript (ES6+)
